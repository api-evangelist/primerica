# Primerica

> Primerica, Inc. (NYSE: PRI) is a US and Canadian financial-services company that distributes term
> life insurance, mutual funds and annuities, mortgages, debt-consolidation, auto & home insurance,
> pre-paid legal and identity-theft protection to middle-income households through a large independent
> sales force. Primerica does NOT operate a public API programme: there is no developer portal, no
> published OpenAPI/AsyncAPI/GraphQL/WSDL contract, no SDK on any package registry, no MCP server and
> no API pricing. The machine-readable artifacts it does publish are OAuth 2.0 / OpenID Connect
> discovery documents for the identity systems behind its own first-party applications.

## What is actually callable

- No public or partner API is documented. Every endpoint below authenticates Primerica's own
  customers or representatives and requires a Primerica account.
- Primerica's API gateway is https://gtw.primericaonline.com (Broadcom/CA Layer7 — unmatched paths
  return a SOAP "Policy Falsified" fault). Its backend-for-frontend routes, e.g.
  /prod/exp/pc2/bff and /prod/exp/client/login-bff/v1/oidc, are credential-gated and undocumented.
- Primerica's own OIDC metadata advertises a Swagger document at
  https://gtw.primericaonline.com:8443/apidocs/auth/oauth/v2/swagger — port 8443 is not reachable
  from the public internet, so that description cannot be retrieved.
